# Superstore Sales Dashboard

## Project Overview

An interactive Power BI dashboard built using the Sample Superstore dataset to analyze sales, orders, profit, and regional performance.

## Dashboard Features

* Total Sales
* Total Orders
* Total Profit
* Profit Margin
* Sales Trend by Year
* Sales by Category
* Sales by Region
* Sales by Sub-Category
* Interactive Year, Region, and Category filters

## Tools & Technologies

* Power BI
* Power Query
* DAX
* Microsoft Excel / Superstore Dataset

## Key Skills Demonstrated

* Data Cleaning
* Data Transformation
* Data Modeling
* DAX Measures
* Data Visualization
* Business Analytics
* Interactive Dashboard Design
