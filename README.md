# Superstore Sales Dashboard

## 📊 Project Overview

An interactive **Power BI dashboard** built using the **Sample Superstore dataset** to analyze sales, orders, profitability, and regional performance.

The dashboard provides interactive filters and visualizations to explore business performance across different years, regions, product categories, and sub-categories.

## 📌 Dashboard Features

* **Total Sales**
* **Total Orders**
* **Total Profit**
* **Profit Margin**
* **Sales Trend by Year**
* **Sales by Category**
* **Sales by Region**
* **Sales by Sub-Category**
* Interactive **Year, Region, and Category** filters

## 📈 Key Metrics

| Metric        | Description                     |
| ------------- | ------------------------------- |
| Total Sales   | Overall sales generated         |
| Total Orders  | Total number of orders          |
| Total Profit  | Overall profit generated        |
| Profit Margin | Profit as a percentage of sales |
